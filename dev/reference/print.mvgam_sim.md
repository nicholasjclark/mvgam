# Print method for `mvgam_sim`

Delegates to `summary(x)` so the default print is informative.

## Usage

``` r
# S3 method for class 'mvgam_sim'
print(x, ...)
```

## Arguments

- x:

  A `mvgam_sim` object.

- ...:

  Passed to
  [`print.mvgam_sim_summary()`](https://nicholasjclark.github.io/mvgam/dev/reference/print.mvgam_sim_summary.md).

## Value

The `mvgam_sim` object `x`, returned invisibly.
