# Print method for mvgam trend objects

Shows the trend label a fit would print, such as `AR({1, 12})`, with the
columns and settings the constructor holds. Settings left at their
defaults are omitted.

## Usage

``` r
# S3 method for class 'mvgam_trend'
print(x, ...)
```

## Arguments

- x:

  A mvgam_trend object

- ...:

  Ignored.

## Value

The `mvgam_trend` object `x`, returned invisibly.
