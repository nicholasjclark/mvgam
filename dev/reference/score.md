# Generic for posterior forecast scoring

Dispatches to a class-specific method to compute proper scoring rules on
a forecast object. See
[score.mvgam_forecast](https://nicholasjclark.github.io/mvgam/dev/reference/score.mvgam_forecast.md)
for the mvgam method.

## Usage

``` r
score(object, ...)
```

## Arguments

- object:

  Object to score.

- ...:

  Method-specific arguments.

## Value

Method-dependent; see the relevant method.
