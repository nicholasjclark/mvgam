# Print the Stan program of an mvgam model

Writes the program of
[`stancode.mvgam_formula()`](https://nicholasjclark.github.io/mvgam/dev/reference/stancode.mvgam_formula.md)
one line at a time.

## Usage

``` r
# S3 method for class 'mvgamstancode'
print(x, ...)
```

## Arguments

- x:

  An `mvgamstancode` object.

- ...:

  Ignored.

## Value

`x`, invisibly.
